# 鲸语 · dsh-whale-whispers

鲸鱼的声音能穿过整片海。

你随口说出的那句，说完就沉下去了——鲸语把它捞回来，收进会话头部的「鲸语」标签页，不催你，也不提醒你。等哪天你想再听，点开就是。

它做三件事：

- 让人看：会话头部的 **鲸语** 标签页（设置里也留一份），句子都在里面，最新在上；
- 让 agent 自己存：三个工具，任何能调工具的 agent 都能往里加一句、读回来、删掉收错的那句——不用人去改文件；
- 让人自己管：改名、换文件、删某一句、导出，都在面板上点。

### 点进去才读文件

面板只在**你切到它**的时候读一次文件，后台不轮询、不耗一分钱。你（或 agent）刚往里写过东西，切出去再切回来就是最新的。

---

## 给 agent 的三个工具

| 工具 | 作用 |
|---|---|
| `whale_whisper_append` | 收一句，写进今天那一段；重复的自动跳过 |
| `whale_whisper_list` | 读回最近的句子（查重、看自己收过什么） |
| `whale_whisper_remove` | 删掉一句（整句匹配，不会误伤旁边那条） |

写进去是原子的（临时文件 + rename），格式跟文件里原有的一样：`- 「句子」（批注）`。

想让它自动收，只要在 agent 的规矩里写一句：

> 觉得某句话值得留，就调 `whale_whisper_append` 收进鲸语，别问。

## 面板上的事

| 想做什么 | 点在哪儿 |
|---|---|
| 改名字 | 右上角「改名」，回车即存（写进 `quotes.config.json` 的 `title`） |
| 换语录文件 | 顶部「换文件」，填绝对路径（写进 `path`；文件还不存在也能先存） |
| 删一句 | 句子右边的 `✕`，再点「删」确认 |
| 复制全部 | 顶部「复制全部」（Markdown，带日期/批注/上文） |
| 下载 | 「下载 .md」，文件名跟标题走 |
| 给别人看 | 「匿名版」，只留句子，去掉批注与上文 |

## 换成你自己的那份

建一个 `quotes.config.json`：

```json
{
  "path": "C:/Users/you/quotes.md",
  "title": "我的鲸语"
}
```

它会在两个地方找这个文件（先找到先用）：`~/.dsh/quotes.config.json`，以及作者机器上的 `D:\dsh work\self\quotes.config.json`。两个字段都可以不填，不填就退回到作者那份。

想完全绕过配置文件，也可以直接给环境变量：

```bash
DSH_WHALE_WHISPERS_PATH=/home/you/quotes.md
DSH_WHALE_WHISPERS_TITLE=我的鲸语
```

## 语录文件长什么样

`##` 写日期，`-` 写句子。句尾跟一个 `(批注)`，会显示成灰色小字。

```markdown
# 我的鲸语

## 2026-11-03

- 「这句话是我想说的。」
- 「这句后面带个批注。」（为什么记它）
  ↳ 上文：这句话是在什么情形下说的
```

句子下面紧跟一行 `↳ 上文：…`，面板会把它显示成暗色小字——单独一句常常少了语境，这一行就是留给语境的。

`whale_whisper_append` 只会改 `- ` 开头的行，你手写的标题、注释、空行都不会被动。

## 它怎么工作

- Host 半边：一个 `GET /dsh-quotes.json`（每次请求现读文件，不缓存）+ 三个工具；
- 两半边共用同一个 `resolveTarget()`，所以面板看到的和工具写进去的永远是同一份文件；
- Client 半边：注册进 `conversation.composer.dock`。

## 安装

```bash
dsh plugin add dsh-whale-whispers
```

或者用 Web UI 的插件市场（本地包）选这个目录。装完重启 DSH。

需要带 Web 客户端的 DSH（`@deepseek-ai/dsh-client-ui-conversation`）。
