# 鲸语 · dsh-whale-whispers

> 装了的话麻烦点个 ⭐（仓库右上角），让我知道有人在用；
> 装不上、用着别扭、想要什么功能，直接在市场页的评论区留言，或开一个 [Issue](https://github.com/heiyedehen/dsh-whale-whispers/issues)——都会看到。

鲸鱼的声音能穿过整片海。

你随口说的那句话，说完就沉下去了——鲸语把它捞回来，收进会话头部的「鲸语」标签页，不催你，也不提醒你。等哪天想再听，点开就是。

## 三处入口

- **会话头部的「鲸语」标签**：句子都在里面，最新的在上；能搜、能筛、能翻。
- **每条回复下面那个书签图标**：点一下，这一条回复就收进去（设置里可以关掉）。
- **设置 → 鲸语**：改名、备份、恢复、规则、回收站，都在那儿。

## 每个对话一本

默认按会话名分本：你在「鱼搭子」里记的句子，只进 `鱼搭子.md`；换到别的对话，看到的是别的本子。

- 顶部下拉可以切「全部对话」（汇总看）或某一本；
- 右上角「改名」改的是**这本的文件名**，会话再打开还是它；
- 设置里那一行开关是**这个对话**的启用状态：停用后它不再自动记，也不建新本；手动加一句仍然可以。

## 不想让它写的时候

三种状态，别混着理解：

| 操作 | 效果 |
|---|---|
| 关掉「对话」开关 | 不再自动记；手动「加一句」还能用；进对话不建新本 |
| 「把这本移走」 | 移到 `quotes/.trash`，下拉里不再出现；不自动记、不能手写、进对话不建本 |
| 回收站里「清空」 | 文件真删、删了不能恢复；对话保持隐藏，不会自己回来 |

移出过的对话想回来，去设置最下面点「重新启用这本」，会新建一本空的。

## 让它记什么

默认规则写在系统提示里：**判断、比喻、认输、承认**这类才记，寒暄和进度不记。

嫌不够，可以在设置里补：

- **全局**：所有对话都用这一条；
- **本对话**：只给当前这一本用，优先级高于全局；
- **频率**：保守（只记明说的）/ 正常（一段对话一两句）/ 积极（遇到像样就记），对新会话生效。

留空就是默认规则，最多 400 字。

## 面板上还能做什么

| 想做什么 | 在哪儿 |
|---|---|
| 搜句子 | 顶部搜索框，句子、批注、上文都能命中；「搜本对话 / 搜全对话」切换范围 |
| 只看收藏 | 句子右边的星标，点一下收藏；「只看收藏」过滤 |
| 按时间筛 | 全部 / 近一周 / 近一月 |
| 翻一句 | 随机翻一条旧的出来看看 |
| 复制一句 | 句子左边的复制图标 |
| 删一句 | 句子右边的 ✕，两下确认 |
| 备份 / 下载 | 设置里「这本（.md）」或「全部（.md）」；工具条上的「匿名版」去掉批注与上文 |
| 恢复 | 选一份之前备份的 .md 覆盖当前文件（旧文件另存 `.before-restore-`） |
| 回收站自动清理 | 开关 + 保留天数（默认关，关了就一直留着） |

## 给 agent 的工具

| 工具 | 作用 |
|---|---|
| `whale_whisper_append` | 收一句；重复的自动跳过 |
| `whale_whisper_list` | 读回最近的句子（查重、看自己收过什么） |
| `whale_whisper_remove` | 删掉一句（整句匹配，不会误伤旁边那条） |
| `whale_whisper_merge` | 合并重复句，只留最早那条，返回删了几条 |

写进去是原子的（临时文件 + rename），格式跟文件里原有的一样：`- 「句子」（批注）`。

想让它主动收，在 agent 的规矩里写一句：

> 觉得某句话值得留，就调 `whale_whisper_append` 收进鲸语，别问。

## 文件长什么样

```
~/.dsh/whale-whispers/quotes.md      # 默认位置
```

`##` 写日期，`-` 写句子，句尾 `（批注）` 显示成灰色小字：

```markdown
# 我的鲸语

## 2026-11-03

- 「这句话是我想说的。」
- 「这句后面带个批注。」（为什么记它）
  ↳ 上文：这句话是在什么情形下说的
```

按对话分本时，每份文件开头会有 `<!-- sid:… -->` 记它属于哪个会话；句子下面跟一行 `收录自：会话名`。

`whale_whisper_append` 只改 `- ` 开头的行，你手写的标题、注释、空行都不会被动。

## 配置

`~/.dsh/quotes.config.json`（找不到就退回插件默认：`~/.dsh/whale-whispers/quotes.md` + 标题「鲸语」）：

```json
{
  "path": "C:/Users/you/quotes.md",
  "title": "我的鲸语",
  "captureLevel": "normal",
  "captureRule": "",
  "captureRules": { "鱼搭子": "只记技术结论" },
  "manualAdd": true,
  "msgAction": true,
  "trashAuto": false,
  "trashDays": 30
}
```

也可以用环境变量绕开：`DSH_WHALE_WHISPERS_PATH`、`DSH_WHALE_WHISPERS_TITLE`。

## 它怎么工作

- Host：`/dsh-quotes.json`（每次现读文件，不缓存）、几个改配置与收句子的路由、四个工具；
- Client：注册进会话头部的 `鲸语` 标签、每条回复的 `assistant-actions`、`settings.section`；
- 面板只在切到它时读一次文件，后台不轮询，不额外花一分钱。

## 安装

```bash
dsh plugin add dsh-whale-whispers
```

或用 Web UI 的插件市场选本地目录。装完刷新页面；改到 host 半边才需要重启。

## 装了却看不到

1. `dsh.client.inject` 里写的客户端包必须本机真有（这份用 `dsh-client-runtime` + `dsh-client-ui-renderer` + `dsh-client-ui-layout`）；
2. 模块 id 必须等于包名（`dsh-whale-whispers`），错一个字母就静默不挂载；
3. 改完刷新页面（client 半边不会自动重载）；
4. 还空就看开发者控制台有没有 `failed to load module`。

## 版本

版本号在插件页和设置里的「更新」一行都能看到。想升级：

```bash
dsh plugin add dsh-whale-whispers@latest
```

装完刷新页面即可，数据（`quotes.config.json` 与各本 .md）不会动。
